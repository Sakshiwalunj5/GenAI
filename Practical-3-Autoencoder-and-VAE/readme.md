
# Practical No. 03: Autoencoder and Variational Autoencoder for Image Reconstruction

## Overview

This practical implements a Convolutional Autoencoder and a Variational Autoencoder (VAE) using TensorFlow and Keras. Both models are trained on the MNIST handwritten digit dataset to reconstruct images. The VAE is also used to generate new digit-like images by sampling from its latent space.

The practical compares both models using reconstruction visualizations, training and validation loss curves, and Mean Squared Error (MSE).

## Objectives

- Implement a Convolutional Autoencoder for image reconstruction.
- Implement a Variational Autoencoder for image reconstruction and generation.
- Understand encoder, latent representation, decoder, and latent-space sampling.
- Compare reconstruction quality using visual results and MSE.
- Analyze the differences between deterministic and probabilistic latent representations.

## Dataset

**MNIST Handwritten Digit Dataset**

- Image dimensions: 28 × 28 pixels
- Image type: Grayscale
- Classes: Digits 0–9
- Training images: 60,000
- Test images: 10,000
- Preprocessing: Pixel values normalized to the range 0–1, with a channel dimension added.

The dataset is loaded using `tensorflow.keras.datasets.mnist`.

## Implementation

### Part A: Convolutional Autoencoder

The Autoencoder consists of an encoder, a compact latent representation, and a decoder. The encoder extracts image features and reduces their spatial dimensions, while the decoder reconstructs the original images.

- Latent dimension: 32
- Optimizer: Adam
- Reconstruction loss: Mean Squared Error (MSE)
- Training epochs: 10

### Part B: Variational Autoencoder (VAE)

The VAE learns a probabilistic latent representation using the mean and log variance. A sampling layer uses the reparameterization trick to generate latent vectors. The decoder reconstructs images from these vectors.

- Latent dimension: 16
- Optimizer: Adam
- Reconstruction loss: Binary cross-entropy
- Regularization: KL-divergence
- Training epochs: 10

### Part C: Performance Comparison

Both models are evaluated on the same test images.

The comparison includes:

- Original and reconstructed image grids.
- Training and validation loss plots.
- Test-set reconstruction MSE.
- A bar chart comparing reconstruction MSE.
- New images generated by sampling from the VAE latent space.

A lower MSE indicates lower pixel-wise reconstruction error. The VAE's total loss also includes KL-divergence, so it should not be directly compared with the Autoencoder's MSE as though they were the same metric.

## Results and Discussion

The Autoencoder learns a deterministic latent representation, while the VAE learns a probabilistic latent distribution.

Reconstruction quality is assessed using visual comparisons and test-set MSE. The VAE's generated-image grid demonstrates image generation through latent-space sampling.
